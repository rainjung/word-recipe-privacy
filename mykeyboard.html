개인정보 처리 방침

마이 키보드 (My Keyboard)  ·  시행일: 2026년 6월 11일

마이 키보드(이하 "앱")는 iOS용 천지인 한글 키보드 확장(Custom Keyboard Extension) 앱입니다. 본 방침은 앱과 키보드 확장 프로그램이 사용자의 정보를 어떻게 처리하는지 설명합니다.

1. 수집하는 개인정보 항목

앱은 외부 서버를 운영하지 않으며, 이름·이메일·전화번호·생년월일 등 어떠한 개인 식별 정보도 수집하지 않습니다.

키보드 입력 내용, 입력 예측을 위한 학습 데이터, 사용자 설정 (테마·키 높이·햅틱·단축어 등)은 모두 사용자 기기 내부(App Group 저장소)에만 저장되며, 외부 서버로 전송되거나 제3자에게 제공되지 않습니다.

2. 키보드 접근 권한 (전체 접근 허용)

앱이 제공하는 키보드는 "전체 접근 허용(Allow Full Access)"을 요구하지 않습니다. 인터넷 통신이나 다른 앱과의 데이터 공유 없이 동작하며, 입력하신 내용은 키보드 또는 앱 외부로 전송되지 않습니다.

3. 인앱 구매(Pro 잠금 해제)

상품 Pro 잠금 해제 (1회성 비소모성 구매) — 자판 강조 색상 추가, 단축어 기능
결제 처리 Apple App Store 결제 시스템(StoreKit)을 통해서만 처리됩니다. 신용카드 등 결제 수단 정보는 앱이 직접 수집·저장하지 않으며, Apple이 처리합니다.

Apple의 결제 정보 처리에 관한 자세한 내용은 Apple 개인정보처리방침을 참고하세요.

4. 보관 기간 및 파기

구분 보관 기간
키보드 설정, 단축어, 입력 학습 데이터, 구매 상태 (기기 내) 앱 삭제 시 즉시 파기

단축어는 설정 화면에서 사용자가 직접 추가·삭제할 수 있습니다.

5. 제3자 제공 및 분석 도구

앱은 광고 SDK, 분석(Analytics) 도구, 크래시 리포팅 등 어떠한 제3자 추적 도구도 포함하지 않습니다. 위 3항의 인앱 구매 처리를 위해 Apple Inc.가 관여하는 것 외에는 어떠한 업체에도 정보를 제공하지 않습니다.

6. 아동 개인정보 보호

앱은 만 14세 미만 아동을 대상으로 하지 않으며, 아동으로부터 의도적으로 어떠한 개인정보도 수집하지 않습니다.

7. 개인정보 보호 조치

  • 모든 데이터는 사용자 기기 내부에만 저장 (외부 전송 없음)
  • 네트워크 통신 기능 미포함
  • 광고 추적 SDK 및 외부 분석 도구를 일절 사용하지 않습니다.
